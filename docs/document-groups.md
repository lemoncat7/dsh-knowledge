# 知识文档分组

分组属于单个知识库，与标签、笔记文件夹和知识库分组相互独立。

- 新建知识文档必须指定分组；优先从已有分组选择，没有合适分组再新建。
- 自动回写会读取目标知识库的分组目录，交给提取模型优先匹配；更新已有文档保留其原分组。
- 目录和会话右侧栏按分组折叠展示。分组数量表示当前已加载文档数。
- 可通过“整理分组”批量归类（每次最多 500 篇），或将文档拖到同一知识库的分组中。
- 升级不擅自归类历史文档，它们保留在“未分组”。归类不改变文档编号、文件路径、正文、标签或已解决状态。
- 取消归类不会删除文档。分组名最多 64 字，统一全半角及多余空格，同库忽略大小写复用已有名称。
- 升级前已生成但尚未执行完的旧回写计划，缺少分组时归入“历史回写”，保持原内容和幂等重试，不重新生成整份计划；后续可批量调整。

数据库升级至 schema 15，仅新增分组元数据。回退旧版本前应恢复升级前数据库备份。

## 会话工具

普通会话与伙伴会话共用两个工具，无需伙伴专属能力：

- `knowledge_document_groups`：分页浏览当前会话挂载范围内的文档分组、文档标题、版本和签名句柄；遵守项目与标签过滤，不返回正文。分组计数仅代表本页，需继续读取 `nextCursor` 获取后续分组。
- `knowledge_document_group_assign`：将 1–50 篇文档归入指定非空分组。传入上述句柄和版本，优先复用已有组。逐篇返回 `applied`、`unchanged`、`pending-review` 或 `failed` 等状态，不假定整个批次原子成功。

只读挂载禁止修改，审核挂载生成候选，直接写入挂载立即调整。文档或权限变化会阻止过期操作，失败项重新读取后可重试。分组调整不修改正文或完成状态，已解决文档也可以归类。
