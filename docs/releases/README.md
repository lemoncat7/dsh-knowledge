# 发布说明维护

[返回项目介绍](../../README.md) · [GitHub Releases](https://github.com/lemoncat7/dsh-knowledge/releases)

README 只维护当前功能、安装方法、适用边界和文档入口，不逐版追加更新日志。详细配置放在使用文档中。

每次发布：

1. 在本目录维护 `<version>.md`，记录该版变更、兼容要求、迁移注意事项和实际验证范围；历史说明不代表当前行为。
2. 将对应说明同步到 GitHub Release 正文，使用有效的绝对文档链接；不要只放一句更新摘要或指向 README。
3. 核对版本标签、npm 版本与附件的一致性，优先使用已验证的同一安装包，不重新构建替换旧版本附件。
4. 同一版本复用已有 Release；发布后检查不再遗留重复草稿。补发历史版本不能将它设成 Latest，撤回版本不能自动重新发布。

本次从 README 迁出的历史段落保存在对应版本文件中。尚未正式发布的说明文件不代表该版本可用，请以 GitHub Release 和 npm 实际记录为准。
