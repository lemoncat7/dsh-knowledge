# 2.16.0 — 检索索引与可见进度

兼容 DeepSeek Harness `^0.2.1-rc.2`；Node `^22.19.0 || >=24.0.0`。

- 已有和新增知识文档自动分批建立结构索引，保留标题路径、段落位置、Unicode 偏移与行号。原文不变，不引入模型请求或向量服务。
- 文档更新后旧索引立即失效，按版本/正文哈希更新；服务重启后继续处理，失败退避重试，未就绪时继续按需解析检索。
- 知识文档目录的搜索框下方展示就绪、待处理和失败状态，点击查看分页详情，管理员可单篇或批量重试。知识库详情中沿用同一入口。
- 状态和重试遵守当前知识库、会话挂载、项目及标签范围；中央连接显示中央服务进度。读取者可查看、不能重试。
- 轮询仅在可见知识目录/详情中进行，不重建编辑器；不支持状态接口的旧服务显示明确提示。
- 同章节相邻片段补充上下文，保留连续证据及长度预算；增加本地检索评测脚本。当前样例是回归用例，不代表线上真实问题质量，也不保证全场景提速。

部署须升级实际保存文档的知识库服务。只升级连接中央服务的客户端不会给旧中央服务建立索引。SQLite 派生索引为可重建的附加表，历史正文与历史回答不改写。
