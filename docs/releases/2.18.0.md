# 2.18.0

新增笔记离线副本与普通 Markdown 文件工作区：远程作为共享版本，本地可靠保存，断网后补同步；请求去重、数据库身份绑定、完整清单校验、整树删除核对及冲突确认防止重复写入和静默覆盖。页面和 AI 笔记工具共享同一副本。

本地 vault 可供 Obsidian 等软件打开，支持正文编辑与新建 Markdown 回流。外部删除、改名、移动、二进制覆盖及两类软件的专有链接语法不自动映射。正文不注入插件字段；`.obsidian` 等隐藏目录不导入。文件级互操作经过验证，未宣称 OB 桌面程序实测。

笔记 schema 升为 4；升级及回滚需备份/恢复笔记目录。远程两端都需升级。现有本地库不会在切换远程时自动上传；首次远程以远程库为起点。详见 [工作区说明](../note-workspace-sync.md)。保持原工具确认规则，其他插件和会话上下文不变。
