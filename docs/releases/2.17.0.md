# 2.17.0

支持 DeepSeek Harness **0.2.1-rc.2**，需要 Node.js **^22.19.0 或 >=24.0.0**。

- 19 项知识库／笔记操作收拢为一个 `knowledge` 工具入口，使用 list / describe / call 按需发现和执行。
- 保留会话与项目挂载、引用隔离、版本冲突、审核、笔记整批预览和下一轮确认；不增加任意知识正文写入能力。
- 完整参数规范按需返回，执行前严格校验；自动召回、回写、日报、引用跳转和 HTTP API 不变。
- 伙伴配套兼容关注检查与 fork Skill 的旧操作白名单，不扩大写权限。部署时需带上伙伴兼容补丁。

自定义工具白名单与按旧名执行的外部策略请参阅 [统一工具入口](../tool-entry.md)，不要把旧只读白名单直接改成无限制入口授权。
