# 2.9.5

插件正式版，适配 DSH 0.1.5 的主面板与原生右侧标签 API，保留旧版主面板回退。已在 DSH 0.1.5-rc.1 镜像验证；DSH 本身仍是 RC 版本。

- 知识库工作区使用新版主面板导航，右侧知识栏支持多插件标签共存及独立关闭。
- 从宿主会话状态恢复工作区上下文；新版空白会话也可使用知识侧栏，旧宿主限制保持不变。
- 隐藏标签停止内容轮询，切换会话或卸载时取消待执行的打开请求。
- 右侧栏入口使用 SSH 同款图标、大小和方向；移除搜索输入框被主题强加的绿色焦点圈。
- 不修改知识内容、挂载授权、回写规则或笔记数据，无新增数据迁移。

验证：171 项自动化测试通过；新版多标签共存、开关与工作区浏览器验证通过。
