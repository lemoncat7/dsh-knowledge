# 2.22.8

- iCloud 同步的删除待处理项增加明确选择：本地条目已移除时可仅保留 iCloud，或再次确认删除对应的 iCloud 条目；远端条目已移除时可仅保留知识库。默认仍不跨端自动删除。
- 删除请求携带已核对的 ETag；远端版本已变化时取消本次删除并重新提示处理。已不存在的远端条目视为删除完成，避免重复操作。
- 本地笔记目录的索引仅在持久化内容变化时写入并同步落盘。空闲扫描保留索引文件的 inode 与修改时间；写入失败会在后续扫描重试，实际笔记修改、冲突与移动检查点继续保存。
- 验证覆盖 iCloud 删除确认、版本变化、单端保留、条件 DELETE，以及笔记目录空闲扫描、写入重试、编辑和重启恢复。iCloud 协议测试使用模拟服务，不对真实日历执行测试删除。
