# 2.15.5 · 主动记录踩坑与召回摩擦 · DSH 0.2.1-rc.2

## 兼容要求

支持 DSH **0.2.1-rc.2**（声明 `^0.2.1-rc.2`），Node.js **^22.19.0 或 >=24.0.0**。使用中央知识库时，客户端和中央服务均需更新，以使用新增反馈接口。

## 更新

- 所有会话注册 `knowledge_record_incident`，不局限于伙伴。挂载说明引导 agent 在实际失败或用户明确纠正后主动记录，不要求用户另说“记一次踩坑”。
- 保存关联文档、来源会话、稳定事件键、具体依据、经验及严重程度；记录直接参与已有摩擦计算和相关性分档内排序。
- 同会话、同文档、同事件键去重；内容变化返回冲突，独立复发才新增。无关文档、推测、普通等待不应计入。
- 不修改正文和文档版本；只读挂载拒绝记录，中央接口需要读写权限，敏感内容需先脱敏。管理员可从现有记录页面撤销误记。

## 验证

- 验证实际工具调用后摩擦增加、真实搜索排序变化，原始相关性不变；重试不重复加分，撤销后恢复排序。
- 验证中央 HTTP 接口读写权限和远程搜索的摩擦排序分数。
- 使用线上容器已安装代码、独立临时数据库验证，不改动用户真实知识和统计。
- 完整回归 365 项测试通过。

模型仍需判断并调用工具，不是无条件后台自动采集；不同会话、不同事件键的语义重复不保证自动识别。摩擦不改变召回准入阈值，不让无关知识越级召回。
