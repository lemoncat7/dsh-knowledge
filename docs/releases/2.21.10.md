# 2.21.10

- 工作日历的目标详情新增「每日进度」弹窗，可以按日期查看、补写、编辑和删除进度，并分页浏览历史。目标结转后共享同一份进度历史，创建日期显示原始目标的创建日期。
- 具体时段的起止日期和时间并排显示。结转目标默认选中结转前一天，便于补写。
- `knowledge_calendar` 支持 `progress-read` 和 `progress-write`。写入沿用请求编号、日历身份和修订号检查，防止重试重复写入或覆盖其他更新。

升级后重启对应的 DSH Profile。每日进度表会随数据库初始化建立，原有日历条目和工作日报可继续使用。详细入口见 [工作日历](../work-calendar.md)。

使用 Node.js 24 完成构建，505 项测试通过。
