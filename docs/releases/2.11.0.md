# 2.11.0 · DSH 0.1.7 适配

正式版。适配并验证 DSH **0.1.7-rc.2**，Node.js **^22.19.0 或 >=24.0.0**。
本版覆盖 0.1.6-alpha.2 起的宿主破坏性变更；**0.1.5 及更早宿主请继续使用 2.10.1**（图标改名为单向迁移）。

- 修复图标渲染崩溃：`dsh-client-ui-primitives` 尺寸后缀图标在 0.1.7-alpha.1（`4937343a5e`）全量改字重新名，三个源文件改为 `XxxOutlineRegular as XxxOutline16` 别名导入，调用点与契约测试保持旧名。
- 修复回合尾回写状态条：`conversation.chat.turnTail` 在 0.1.6-alpha.2（`577e4a036d`）由 chain 改 list，注册改用必填 `id: 'knowledge-writeback-status'`，轮次从 owner props `turn.turn` 读取，不再抛未捕获异常。
- 修复停靠侧栏打不开：`SessionListState.current` 在 0.1.6-alpha.2（`6830e1460d`）被移除，新增 `deriveCurrentSession` 结构桥——优先读 `retainedBy.mainView > 0` 推导、回退旧 `current` 字段；launcher、工作区、活动控制器与停靠"等待会话提交"共 5 处统一走该桥。
- 连接设置卡片迁移：`settings.plugin.item` 槽位在 0.1.6-alpha.2（`90af3110b7`）退役，卡片改注册为设置「内置插件」分区的「知识库」标签页（`settings.plugins.tab`，0.1.5/0.1.7 官方同款写法）。
- 修复会话运行失败「format v4 message requires a producer-owned source kind」：DSH 0.1.7 新增会话消息 source 校验、退役 `{ kind: 'plugin' }` 包装，recall 注入消息与抽取请求消息改用 producer-owned `kind: 'plugin:dsh-knowledge'`（官方 `producerKind` 的 `plugin:<name>` 规则），历史注入消息的识别与清理新旧形状双兼容。
- 开发依赖 11 个 DSH 客户端包升至 0.1.7-rc.2 并新增 `dsh-client-ui-settings`；`src/legacy-slots.d.ts` 以 DSH 官方声明合并扩展点桥接旧宿主回退分支的 `SlotMap.conversation`/`details` 与 `ILayout.openDetails/closeDetails`，`tsc --noEmit` 全绿。
- `dsh.client.inject` 10 包、`cordis.patch.yml` 方言与 peer `@deepseek-ai/cordis ^4.0.1` 均不变；数据库无变更。
- 186 项测试中 168 项通过，18 项失败与 2.10.1 干净基线完全一致（本机 Windows 的 `0o600` 权限位断言与 SQLite EBUSY 文件锁，与升级无关，已用 git worktree 基线对照确认）。
- 升级前建议备份插件及数据。
