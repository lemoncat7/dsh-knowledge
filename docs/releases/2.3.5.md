# 2.3.5

正式版，适配 DeepSeek Harness `0.1.2-rc.1`，需要 Node.js `^22.19.0 || >=24.0.0`。

## 修复与优化

- 修复回写前将整段对话拼入搜索 URL，导致入口返回 HTTP 400 / 431 的问题。
- 自动检索优先提取问题关键词、章节标题和代码标识，限制词数和编码后长度；不增加模型调用，原始对话仍完整传给提取模型（保留原有上下文上限）。
- 超过 6,000 编码字节的搜索 URL 改用带鉴权的 POST JSON 请求体，服务端继续支持 GET。
- 仅在旧服务端明确不支持 POST（404 / 405 / 501）时，降级为短关键词 GET；保留项目、知识库、标签和类型范围，不绕过权限或忽略检索失败。
- 搜索错误不再回显整段对话 URL 或代理错误正文；正确识别代理返回的非 JSON 错误状态。
- 不更改 UI、主题、知识数据格式或回写权限。

## 升级

```bash
dsh plugin --profile web add @lemoncat7/dsh-knowledge@2.3.5
```

远程部署建议同时升级中央服务和发起回写的客户端。只更新服务端，不能修复旧客户端发送的超长 GET URL。升级后重启对应 DSH，再手动重试之前失败的回写；本次升级不会自动重放历史写入。
