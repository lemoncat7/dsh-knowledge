# 2.21.3

工作记录新增独立的「工作日历」，用于管理每日目标和具体时段安排，原有「工作日报」继续保留独立入口和页面。

- 支持月/周浏览、当天目标、全天或具体时段、完成进度、标签与优先级、回收站恢复及 `.ics` 导出，兼容深浅色主题与手机布局。
- AI 可通过统一 `knowledge` 入口发现并调用 `knowledge_calendar`，查询、创建、修改、删除及恢复目标。日历遵循当前本地/远程连接，使用幂等请求编号和版本冲突检查，减少重试重复创建或并发覆盖。
- 在回收站选择日期、切换月份或周、跳转今天等操作会自动返回正常日历；提供直接返回按钮，修正切换时短暂显示上一模式目标的问题。
- 完成勾选框与整项目标内容垂直居中，长标题、时间及标签改变条目高度时自动对齐。

升级 `@lemoncat7/dsh-knowledge@2.21.3` 后重启对应 Profile。新增日历表与原有工作记录兼容，原日报链接和数据保留。工具与使用说明见 [工作日历](../work-calendar.md)。

本版预留 Google Calendar / CalDAV 适配器类型与增量变更接口，尚未连接外部账号，也不会自动执行目标或推送提醒。
