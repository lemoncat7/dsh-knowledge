# 2.13.6 · 输入框 @ 笔记文档

适配 DSH **0.2.0-rc.2**；需要 Node.js **^22.19.0 或 >=24.0.0**。

- 在原有输入框 `@` 菜单中增加「笔记文档」分组，跨目录按标题搜索，仅列出笔记文档，不混入知识条目、目录或上传附件。
- 沿用宿主的方向键、Enter、Tab 和 Escape；文件、会话搜索和文件夹下钻保持不变。搜索防抖并取消过期请求。
- 选取结果插入绑定稳定文档 ID 的引用，点击可打开笔记。发送时重新核验来源和文档，生成当前会话可用的读取句柄；重名或改名不串文档，已删除文档和切换来源明确报错。
- 搜索和引用序列化只读取元数据，不把笔记全文塞进输入框；引用不授予修改或删除权限，原有确认规则保持不变。
- 本地和远程接口支持文档类型过滤及跨目录列举。使用远程知识库时，服务端也应升级；旧服务的候选结果可能不完整。

验证：259 项测试通过，包括实际 DSH 输入触发控制器的键盘选取、取消与来源共存检查；线上已验证前端加载、笔记搜索和读取句柄生成，未发送测试对话或修改笔记。

详见 [笔记文档引用](../note-mentions.md)。
