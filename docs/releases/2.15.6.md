# 知识库 2.15.6

支持 **DeepSeek Harness 0.2.1-rc.2**，兼容声明与依赖保持不变。

- 新增“23:30 保底整理”开关，默认开启，可独立于原有每日定时整理关闭或开启。
- 按日报设置的时区，在每天 23:30 补充整理当天未覆盖的素材。没有新素材时跳过，不自动覆盖手工修改的日报。
- 两个整理时点分别记录状态；已有任务运行时等待，防止重复排队。重启后补跑最近错过的时点。
- 已有配置升级后默认开启保底整理；显式关闭会持久保留。中央统一调度，远程采集端不执行本地模型整理。

23:30 后新增的素材仍可手动整理。本次升级不回放启用前的保底时点，不修改原有每日定时整理时间。

验证：371 项测试通过；浏览器覆盖开关保存、刷新、关闭，以及手机、横屏和深色布局。已在生产环境部署，确认保底整理开启、时区为 Asia/Shanghai，215 篇知识文档及其他插件配置保持不变。

安装：`dsh plugin --profile web add @lemoncat7/dsh-knowledge@2.15.6`。安装后重启对应 Profile，并刷新浏览器。
