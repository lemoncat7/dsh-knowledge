# 2.13.5 · 笔记批量修改与完整预览确认

兼容宿主：DeepSeek Harness 0.2.0-rc.2。本版本不调整宿主兼容范围。

- 新增 `knowledge_note_update` 的 `batch_edit` 操作：同一次请求可合并多处修改，统一预览、一次确认、原子保存，不再要求逐章确认。
- 支持整篇改写；局部修改按同一原文快照匹配，检查锚点唯一性、重叠和版本冲突，保留未修改内容。
- 预览展示章节、原始行号及修改前后内容，明确说明改了哪里。
- 新增通用会话工具 `knowledge_note_preview`，用于分页读取较长预览，不限伙伴会话。
- 完整预览读取后才接受后续轮次确认；保留会话绑定、有效期、取消和过期版本校验，防止省略预览或重复保存。

验证：构建通过，252 项测试通过；已在 DSH 0.2.0-rc.2 容器验证部署与工具注册。
