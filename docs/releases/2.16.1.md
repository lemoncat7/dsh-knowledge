# 2.16.1 — 非阻塞加载与后台稳定性

兼容 DeepSeek Harness `^0.2.1-rc.2`；Node `^22.19.0 || >=24.0.0`。

- 目录加载不再等待可选的索引状态组件下载；组件慢或失败时不影响目录使用，失败可就地重试，不重建编辑器。
- 索引状态首次可见时才请求；挂载、可见性事件合并在途请求，遵守就绪 30 秒、处理中 3 秒、网络错误 15 秒的刷新间隔。权限/旧服务错误停止轮询。
- 修复动态模块下载失败后被浏览器缓存、点击重试仍失败的问题，仅失败组件使用新的重试地址，保留发布版本参数。
- 管理台 JSON 读取设置 30 秒超时，包含响应正文读取；保留切页取消语义并清理监听器。写操作不受该读取超时影响，不自动重放任何修改请求。
- 未变化的知识库清单不再反复原子写盘；实际变更或文件缺失仍按原有持久化方式保存。
- 索引按受限批次提交，减少逐篇提交的写盘开销；空闲不启动写事务，存储错误回滚本批并允许后续恢复，保留外层事务回滚语义。

不新增向量模型、外部服务或依赖，不改变文档权限、原文与引用规则，也不改已有布局与配色。

验证：407 项自动化测试通过。真实浏览器故障注入验证了慢模块不阻塞目录、下载失败后重试、初次请求合并、浅深色/窄屏、分页重试、切页清理与旧服务兼容。

边界：本次消除的是插件内部已验证的阻塞和重复工作。主机磁盘 I/O 等待、宿主/主题渲染开销仍可能造成延迟，不能据此承诺线上每次打开的耗时。
