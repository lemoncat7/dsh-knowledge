# 2.23.0

- 日历支持目标、日程、提醒、工作记录，增加分组和类型/关键词筛选、完整列表视图，密集内容不再只能挤在月历格子中。目标继续复用每日进度和工作日结转。
- 明确提醒/目标/日程语义的工具指引，要求实际保存并核对结果。支持独立提醒时刻、DSH 到期提示与持久知晓；按已有可见状态低频检查，不调用模型。iCloud 上传标准日历通知，DSH 关闭时仍可由 Apple 日历通知。
- 已登录 iCloud 可读取账号日历，按分组选择关联及双向、仅上传、仅下载或暂停；独立隔离同步范围，只读日历限制方向。原连接和历史目标保持兼容。
- 修复普通单边删除被当成冲突：正常删除自动传播，删除与编辑冲突仍保留处理入口；恢复复用 UID，持久操作意图处理超时后的未知写结果。单个分组失败不会阻塞其他分组。
