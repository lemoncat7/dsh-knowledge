# 2.16.2 — 宿主入口连接与恢复稳定性

适配 DSH `^0.2.1-rc.2`；沿用现有索引与全文检索，不引入向量模型、第三方 UI 依赖或 DSH 核心修改。

## 改进

- 将工作区和设置页的连接请求收敛到独立连接客户端。同时进行的 GET 共用一次请求，每个调用方可以独立取消，最后一个调用方离开后取消底层读取。
- 连接读取有 30 秒超时（包含响应正文），失败可手动重试。保存配置不套用读取超时，也不会自动重放写入。
- 初始绘制只使用 30 秒内的连接元数据；每次打开仍重新验证。不会缓存正文、凭据或访问授权，不使用永久驻留的 iframe。
- 保存连接配置时使旧读取失效；等保存结束后再读取，防止旧响应覆盖新连接。401/403/404 会清除元数据缓存。
- 工作区关闭、重试时取消过期检查；注销重连监听，迟到响应不再更新已卸载页面。
- 临时断网或 5xx 的后台复查失败时，保留当前 iframe 和编辑内容，显示轻量提示与重试按钮；恢复网络后重新检查。权限拒绝、接口删除或管理台关闭仍撤下页面，不绕过权限。
- 保留现有样式，提示使用知识库自身颜色、圆角与控件变量，不引入新视觉风格。
