# 2.3.6

正式版，适配 DeepSeek Harness `0.1.2-rc.1`，需要 Node.js `^22.19.0 || >=24.0.0`。

本版包含 [2.3.5](./2.3.5.md) 的全部回写检索修复，并补齐依赖锁文件，修复 GitHub 干净构建时 `npm ci` 报依赖缺失或版本不一致的问题。未增加插件的生产依赖，未修改 UI、主题、知识数据格式或回写权限。

- 自动回写使用有界关键词检索，不再将整段对话塞入搜索 URL；原始对话仍按原有上下文上限提供给提取模型。
- 长查询支持带鉴权的 POST；仅在旧服务不支持时降级为短关键词 GET，保留项目、知识库、标签和类型过滤条件。
- 搜索错误不再回显整段对话，检索失败继续停止回写，避免误建重复文档。
- 会话侧栏查询项目目录时保留 DSH 的 `SessionId` 类型，修复完整 SDK 类型检查下的编译错误，不改变界面或交互。
- 覆盖 107 项自动化测试，包括长查询、旧服务兼容、权限、取消和完整回写链路。

```bash
dsh plugin --profile web add @lemoncat7/dsh-knowledge@2.3.6
```

使用远程知识库时，请同时升级中央服务与发起回写的客户端。只更新中央服务不能修复旧客户端发送的超长 GET URL。升级并重启后，可手动重试此前失败的回写；不会自动重放历史写入。
