# 2.11.2 · 回写状态空记录处理

插件正式版，适配并验证 **DSH 0.1.7-rc.2**。Node.js **^22.19.0 或 >=24.0.0**。不声明兼容未经测试的宿主版本。

- 回写记录不存在时返回 HTTP 200 和明确的 missing 状态，避免正常空记录反复产生控制台 404。
- 客户端同时兼容旧版 404/missing 响应；真实接口错误仍显示重试提示，不伪装成记录不存在。
- 旧等待状态仍会清除，记录出现后可恢复；不存在的任务不能假装重试成功。
- 不修改数据库结构、用户配置或回写执行顺序。

验证：构建与 36 项回写相关测试通过。可回退至 2.11.1。
