# 2.13.0 · 中央日报与可靠文档引用

适配 DSH 0.1.7-rc.2，Node.js ^22.19.0 或 >=24.0.0。

- 日报来源统一上传中央知识库，日报、整理模型、时区及定时整理配置由中央管理；采集授权、项目路径保留在本机。
- 支持断网持久排队、退避重试、上传去重、来源隔离及手动重试；中央服务和采集端均需升级。
- 历史日报迁移需明确确认，不覆盖中央已编辑正文，保留本地历史数据。
- 每日定时整理默认关闭，由中央执行；支持时区、重启后补偿及失败重试。
- 文档搜索、读取、分组和状态修改使用会话绑定短引用；保留挂载权限、版本及审核校验。
- 区分引用格式、签名、会话不匹配和失效错误，附重新检索指引；正文匹配失败提供安全诊断，不模糊匹配写入。
- 引用在重启、切换来源、缓存淘汰或空闲 24 小时后失效，需要重新搜索读取；旧完整签名句柄保留兼容校验。

验证：229 项测试通过，中央日报浏览器检查及正式部署页面、接口、Desktop Origin 检查通过。
