# 2.12.1 · 日报完整内置

适配 DSH 0.1.7-rc.2，Node.js ^22.19.0 或 >=24.0.0。

- 日报服务、界面、采集和持久任务全部内置知识库，安装一个知识库插件即可使用。
- 不再需要安装或授权独立的 dsh-worklog 插件。
- 自动复用试用版的相邻 worklog/worklog.sqlite 数据库；新安装独立存储在知识库数据库旁。
- 试用部署升级时必须移除旧 worklog 的 profile bundle 注册，避免双重采集和队列执行；保留数据库。
- 默认关闭采集，支持全部/指定项目、手写路径、DSH 模型选择、来源核对与导出。

2.12.0 的双包发布方案已撤回，此版本取代该方案。
