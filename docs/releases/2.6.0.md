# v2.6.0 · 可靠异步回写

正式版，适配 DeepSeek Harness **0.1.2-rc.1**；Node.js `^22.19.0 || >=24.0.0`。npm 使用 `latest` 标签。

## 更新

- 轮后先把本轮内容快照可靠保存到本机 SQLite 队列，再释放会话结束流程。渠道回复不再等待模型提取或远程知识写入。
- 未完成任务和写入计划持久化，后续对话不覆盖旧任务；服务重启后可恢复。相同会话按顺序回写，前序失败时显示等待原因。
- 自动退避重试、手动重试、重复点击防护；保留失败任务，不重新生成已确定的写入计划。
- 直接写入回执与文档变更同事务保存，避免响应丢失或 Markdown 同步失败时重复追加或生成多余版本。
- 回写状态、文档链接自动更新，离屏暂停查询；恢复可见时补查。修复浏览器 `fetch` 调用接收者错误，读取状态失败不再静默空白。
- 不修改 DSH 源码，不更改现有配色和动画。

## 升级说明

远程直接写入要求中央知识库服务也升级到 **2.6.0**；旧服务缺少幂等协议时会保留计划并提示升级。搭配伙伴 **1.9.2** 使用。旧失败记录若没有持久化快照，不能安全重建重试；正常历史成功记录仍可查看。中断恢复可能需要等待原服务的最长 15 分钟执行租约，活跃任务不会被强制抢占。

## 验证

139 项自动化测试通过，覆盖重启恢复、顺序执行、重复提交、响应丢失和权限撤回。真实 Chromium 验证状态请求与文档链接，完成桌面、375px 手机和 1024px 平板检查。

## 从 README 迁入的历史说明

以下为该版本当时的介绍，适用范围以该版为准，不作为当前使用指南。

正式版 `2.6.0` 适配 DeepSeek Harness `0.1.2-rc.1`，需要 Node.js `22.19+` 或 `24+`。浏览器端使用该版本的 Session Controller、Renderer、Chat、Settings 与 Theme 插槽接口。

`2.6.0` 将轮后回写改为本机持久化队列：先保存本轮快照，再释放会话结束流程，不再等待提取模型或远程写入。失败可在原回答下重试；重启和后续对话不会覆盖未完成任务。状态显示等待回写／回写中／成功及目标文档／失败与原因。远程直接写入需要中央服务同时升级到 `2.6.0`，旧服务不支持幂等回执时会明确报错并保留计划，不冒险重复写入。

前端回写状态自动轮询，修复浏览器原生 `fetch` 的接收者绑定问题；读取失败会明确显示正在重连，不把查询失败误报为写入失败。139 项自动化测试通过，并验证真实 Chromium 中的状态请求、目标文档链接及桌面／手机／平板展示。
