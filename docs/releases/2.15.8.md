# 2.15.8

支持 DeepSeek Harness ^0.2.1-rc.2。

- 知识检索与读取提供可直接使用的行内引用，要求回答在相关句段后使用 `（来源：[文档名 · 第 x–y 行](引用链接)）`。不增加独立来源卡片或将所有候选结果列为已使用依据。
- 适配 DSH 原生 Markdown 文件引用交互，由知识库插件接管保留路径，打开只读来源视图；展示文档路径、章节、版本及带行号原文，高亮引用范围，支持打开完整文档。
- 引用链接不是公开分享或权限凭据。点击重新核验原会话挂载、项目/标签范围、知识库连接和文档版本。失效、取消挂载、删除或版本改变会明确提示，不把旧行号应用于新正文。
- 修复连续父子标题可能仅返回标题、缺少正文的片段问题。
- 明确已有相关自动召回时可直接读取，减少模型重复发现知识库的绕路；不保证模型每次都遵循，不改变旧会话内容。

边界：普通渠道不一定支持 DSH 内部引用跳转，应保留文字来源；历史回答不会自动补写引用。没有新增会话事件类型，没有修改 DSH 核心或自动公开文档。主题相关性过滤和持久化分块/混合检索仍属于后续优化。
