# 2.22.12

- 日历目标栏直接显示最近的日报进度核对结果，默认可重新核对昨日；选中历史日期可核对当日，失败时提供对应日期的重试按钮。提交中和核对中防止重复点击，网络错误允许重新提交；关闭联动时提供设置入口。
- 重试继续只补缺失记录，保留已有进度及人工修改。复用日历现有的更新检查，核对状态变化无需重新读取事件列表；无额外空闲轮询。
- 修复关闭后重新开启仍提交旧核对结果、慢请求把已完成任务改回重试、以及同一时刻的新旧重试结果混淆。每次新任务带独立身份，提交和失败回写均校验当前任务，单实例并发核对合并执行。
- 增加重试风暴、流式截断/网络异常、整批事务回滚、跨连接竞态、重启恢复、人工清空保护、多批次与工作日结转、空闲读写及手机/桌面明暗浏览器回归。
