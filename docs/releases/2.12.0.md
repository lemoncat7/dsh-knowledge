# 2.12.0 · 工作日报工作区

适配并验证 **DSH 0.1.7-rc.2**，Node.js **^22.19.0 或 >=24.0.0**。

- 知识库内部新增「工作记录 → 工作日报」，不增加全局侧栏按钮。
- 需要同时安装 **@lemoncat7/dsh-worklog 0.1.0**；日报独立存储，不写入知识文档。
- 支持按日期查看、补记、整理、编辑、导出和来源核对；采集默认关闭。
- 采集可选择全部、当前/已记录项目或手写路径，整理模型从 DSH 已配置模型中选择。
- 嵌入模块按需加载，统一面板样式，兼容移动端及 Desktop 来源认证。

知识库入口不可用时会显示安装/重试提示，不影响原有知识库功能。工作记录安装说明见 https://github.com/lemoncat7/dsh-worklog 。
