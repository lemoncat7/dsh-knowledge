# 2.22.9

- 空闲远程笔记同步每轮只请求一次清单，不重复下载未变化的正文，不反复写入已删除记录。发生下载或删除时，仍在提交前再次确认远端版本，并保留同步期间的本地修改。
- 同步清单增加节点编号、唯一性与指纹校验。清单不完整或校验失败时保留本地副本，避免将截断结果当作删除依据。
- 本地 Markdown 工作区共用一次完整目录快照，复用文件指纹，减少重复遍历、路径检查和目录创建。活动期间每 5 秒兜底，空闲后逐步放缓至每 30 秒；删除确认期间保留 5 秒检查，文件监听和手动同步继续及时触发。
- 笔记清单与回写状态复用 SQLite 变更检测，识别本连接修改及其他连接提交；可回滚事务中的视图不进入缓存。未变化的索引继续保持原子写入去重与失败重试。
- 知识回写队列空闲时每 30 秒检查一次，不获取写事务；有待处理工作时保留 2 秒调度，新对话入队直接唤醒。状态监听仅在版本变化时通知，运行中任务的租约仍可靠续期。
- 无新增依赖或数据库 schema 变更。网页编辑已保存在数据库后，本地文件投影在空闲时可能等待至下一次扫描，需要立即导出可手动同步。

验证：构建与全部 527 项测试通过，覆盖空闲 WAL/索引不变、清单请求和正文读取次数、清单截断保护、跨连接缓存失效、事务回滚、离线同步、编辑冲突及回写恢复。线上基线与补丁组合另通过 74 项回归；部署后的 3 分钟空闲观察中，知识库索引 inode、mtime 和大小保持不变，警告、冲突及缺失均为 0。观察期结果不代表所有负载下的性能保证。

配置与行为说明见[空闲读写与后台处理](../idle-performance.md)及[笔记工作区同步](../note-workspace-sync.md)。
