# 2.10.0

插件正式版，已在 DSH **0.1.5-rc.1** 本地构建部署验证；DSH 宿主本身仍为 RC。

- 知识文档按知识库内分组展示，支持折叠、拖拽归类和批量整理，会话右侧栏同步展示分组。
- 新建文档必须选择有效分组；自动回写读取已有分组并优先复用，更新已有文档保留原分组。标签功能不变。
- 历史文档保留“未分组”，升级前冻结的旧回写计划缺少分组时兼容归入“历史回写”，保持原幂等凭据。
- 新增通用会话工具 `knowledge_document_groups` 和 `knowledge_document_group_assign`，普通与伙伴会话共用；遵守挂载、项目、标签及读写权限。
- 分组查询分页返回可访问文档的元数据、版本与签名句柄；分组计数代表当前页，可继续读取后续页。
- 分组修改支持每次 1–50 篇，逐篇报告应用、待审核或失败。只读拒绝修改；审核模式生成候选，直接写入模式立即生效。
- 审核页展示分组前后对比；版本变化或权限撤回时阻止过期操作。分组调整不改变正文、标签、路径和完成状态。

验证：186 项自动测试通过，涵盖普通会话、权限隔离、审核、重试、远程 API 和并发版本保护；分组浏览器测试覆盖桌面、手机和平板宽度及浅色/深色主题。

## 升级注意

数据库升级至 schema 15。远程模式需要同时升级知识服务端和客户端。升级前备份数据库，回退旧版插件时恢复对应备份。新文档创建接口现在要求提供有效 `group`；历史文档仍可保留未分组状态。

### 2.10.0 知识文档分组与会话工具

插件正式版，已在 DSH **0.1.5-rc.1** 本地构建部署验证。知识文档支持折叠分组、拖拽及批量归类，新文档必选分组，自动回写优先复用已有分组。普通会话和伙伴会话共用分组查询与修改工具，并遵守挂载、项目、标签和审核权限。

186 项自动测试及浏览器分组回归通过。远程模式需同时升级知识服务；数据库升级至 schema 15，回退前应恢复升级前备份。详见 [更新说明](../../docs/releases/2.10.0.md) 和 [分组使用说明](../../docs/document-groups.md)。
