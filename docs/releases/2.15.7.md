# 2.15.7

支持 DeepSeek Harness ^0.2.1-rc.2。

- 召回排行默认使用可解释的综合得分：召回、阅读、会话覆盖、防踩坑价值和人工优先级共同参与。点击分数查看构成，保留各单项排序。
- 综合得分 = clamp(25R/(R+10) + 25D/(D+5) + 20S/(S+5) + 0.2F + 5P, 0, 100)，保留一位小数。R/D/S 为所选时间窗口内召回/读取/会话数；F 为有效摩擦系数；P 为 −2 到 2 的人工优先级。不依赖当前分页或筛选集合的最大值，不重复累加自动注入与主动搜索。
- 分数只表示展示层的关注价值，不是质量或成功率；不替代真实查询的相关性门槛与排序。摩擦的正向贡献最多 20 分。
- 展示筛选范围内有有效踩坑记录的文档数量，可直达踩坑排行，区分未记录、自动计算和人工覆盖。
- 文档检索后选择实际命中的 Markdown 段落，返回章节、行号、字符偏移和版本；支持按预期版本读取，避免搜索后内容变化导致误读。
- 精确标题检索优先，仍保留原有知识库、项目、标签和权限限制。
- 无新增模型请求，无文档正文迁移，不改变已有踩坑事实。
