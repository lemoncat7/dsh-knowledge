# 2.13.7 · 日报子目录采集与目录树

适配 DSH **0.2.0-rc.2**；需要 Node.js **^22.19.0 或 >=24.0.0**。

- 工作日报新增「包含所选目录的子目录」开关（`recursiveProjects`），默认关闭，保留原有精确匹配。开启后按目录边界覆盖子孙目录，不误收同名前缀的其他项目；支持 POSIX、Windows 盘符和 UNC 路径。排除会话规则保持不变，不补采历史对话。
- 采集目录改为紧凑单行目录树，父目录没有会话也可勾选，递归开关独立于目录树。展开不改变授权；支持方向键、空格、手动添加和一键收起。初次只展开本机默认工作目录的祖先，默认目录本身、子目录和其他分支保持收起；轮询不覆盖手动收起状态。
- 本机候选目录与中央接收的远端目录隔离。迁移旧候选时保留已有采集配置；缺少本机依据的已选路径单独展示，不静默删除或扩大采集范围。默认路径来自 DSH 服务启动工作目录，不取当前会话或中央知识库目录。
- 简化采集设置，将说明集中在两个小型提示中；模型刷新与选择同排，失败保留已有选择。移除目录树下重复路径展示，限制树高度，优化窄屏布局。
- 日报弹窗支持点击外部关闭，未保存修改需确认，保存中禁止关闭，向外拖动不会误关。关闭按钮固定在弹窗内顶部；普通知识库弹窗也改进了外部点击和滚动行为。

验证：276 项测试通过；浏览器回归覆盖递归采集设置、键盘导航、跨实例隔离、离线恢复、弹窗保护及桌面/移动端布局。功能已部署验证，原有采集配置、日报和历史数据未变。

感谢 #14 提供场景分析与补丁建议，本版采用默认关闭的显式开关方案。
