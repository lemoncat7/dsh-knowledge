# 2.20.0

- 本机回写设置新增每 1～20 轮合并提取、空闲 30～3600 秒兜底。默认每轮，保留原行为；只合并同会话、同项目、同来源与同模型路由的新内容，达到输入上限提前处理。
- 待提取快照持久化，支持会话和任务列表“立即回写”；重启恢复、原轮次状态映射、失败检查点和幂等写入沿用可靠队列。手动新建笔记不受频率影响。批量历史不自动执行文档结束状态确认，避免旧确认被重新使用。
- 笔记修改确认支持自然表达与提案后的细节讨论，不因插入讨论立即丢弃方案。明确拒绝或改变要求仍取消旧方案。
- 用户明确授权本次任务中的指定对象直接修改时，基于真实用户上下文进行语义判断，执行服务器保存的具体方案；普通修改仍默认预览确认，永久删除不跳过确认。语义判断不可用或不明确时保留确认流程。
- 保留会话绑定引用、文档版本冲突、预览完整性、权限校验与新输入接管校验。具体人物设定无关。
