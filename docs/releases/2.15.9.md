# 2.15.9

支持 DeepSeek Harness ^0.2.1-rc.2。

- 来源链接悬停或键盘聚焦时按需读取简短原文预览；离开、滚动或 Escape 关闭并中止请求，不后台批量加载所有来源。
- 点击直接进入现有知识文档工作区，在完整文档里定位并高亮对应段落；删除独立来源阅读页，旧引用链接仍兼容。
- 定位以文档实际 Markdown 块的行号为依据，支持段落、标题、列表和代码块，保留权限与版本校验。文档变更时明确提示，不套用旧行号。
- 来源定位使用正文独立滚动区域，不把正文滚到透明标题栏下面；复用文档排版与主题色，引用阅读时正文使用清晰底色。
- 来源模式仅阅读，退出定位恢复原有文档操作；不会修改文档或自动保存。
