# DSH 0.2.2-rc.2 兼容性

验证日期：2026-11-12。插件源码版本：2.19.5。目标宿主：官方 `@deepseek-ai/dsh@0.2.2-rc.2`，Linux Web，Node.js 24.19.0（最低要求 >=24.9.0）。

## 结果

- 构建/类型检查及 462 项测试通过。
- 管理页面、笔记保存和重启持久化、真实 Agent 请求中的知识召回。
- 8 个自研插件同时加载的隔离 rc2 宿主启动、页面和会话检查通过；未使用跳过版本检查的参数。
- 未发现需要修改本插件运行时代码的 rc2 API 不兼容。源码 `engines.dsh` 从锁定 rc1 改为 `=0.2.2-rc.1 || =0.2.2-rc.2`，避免 rc2 在加载前拒绝插件。

## 边界与发布状态

此兼容版本为 2.19.5，基于 2.19.4 已通过回归的运行时代码，仅更新版本、兼容声明及说明。部署与公开发布状态以实际部署记录和仓库 Release 为准；旧制品仍受原兼容声明限制。

检查了官方包内 rc1 → rc2 升级指南涉及的会话 append 重载、运行时上下文、工具 guard、Agent 和 bundle 接口。没有做 macOS Desktop 实机验收，也没有真实 QQ/B 站投递、生产 SSH 操作或付费模型/生图调用；自动化模拟上游不能替代这些外部服务的端到端验证。

完整矩阵及证据见部署仓库 `COMPATIBILITY-022-RC2-20261112.md` ；精简验证证据保存在部署仓库 `reports/compat-022rc2-20261112/test-evidence`，隔离运行环境在部署后清理。此前 rc1 兼容记录保留在 [原说明](compatibility-0.2.2-rc.1.md)。宿主回退须恢复匹配的数据快照，不让旧宿主写入新宿主已迁移的数据。
