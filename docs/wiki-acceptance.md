# Wiki 功能验收清单

本清单区分用户验收、自动化测试和尚未验证项。未勾选不代表失败，也不代表已通过。

## 用户验收

- [x] 目录选择：用户已确认 Windows 原生选择、站内浏览和路径回填可先验收。原生选择结果另有 CP936 环境下中文、空格、emoji 回归。
- [ ] 完整资料入库、会话召回/回写、长期运行和回退仍待逐项验收。

## 安装物

1. 安装依赖，用 Node >=24.9 执行 `node scripts/wiki-build.mjs`（不运行测试）。
2. 构建成功后用 `npm pack --ignore-scripts` 或等价 pnpm 命令生成包。构建失败不拿旧 lib 打包。
3. 在隔离 profile 加载；确认包内含 `lib/wiki`、`web/wiki-workspace.js`、`web/wiki-directory-browser.js`、`scripts/extract-one.py` 和说明文档。
4. 不因插件能启动就卸载旧插件或改动真库。首次验收均使用副本。

## 文件与权限闭环

- [ ] 同标题/正文不同路径的页面分别保持 ID，搜索与读取可区分。
- [ ] 蒸馏更新直接写入（无待审候选、无需批准替换）：只改目标页，不改同源其它页；写入前校验目标页哈希，外部修改则 WIKI_EXTERNAL_EDIT_CONFLICT 且零写入；重复请求不重复记账。普通文档的候选审批流程不受影响（如仍启用）。
- [ ] 重启、删除派生索引并重建后身份、来源与项目权限不变。
- [ ] 未挂载、撤销挂载及无权项目不能通过候选或旧句柄读取正文。
- [ ] 改 SQLite 索引本身不改 Markdown；外部文件变更刷新后可读。

## 自动入库

- [ ] 新文件一次点击直到可检索，同名不同扩展名不碰撞、不改原件 basename。
- [ ] 源根层新文件夹按一次投递递归收集：归档到「分类/投递文件夹名/相对路径」；有归档证据的既有分类目录不再扫描、不重排。
- [ ] 只登记不抽取类型（.mp4/.exe/.rar/.zip/.msi/.7z/.doc）不受 256 MB 限制：原位登记、只写回执、不复制/不移动、不抽取不蒸馏、无 raw 与知识页；可抽取类型超限则跳过并在扫描结果与界面逐条说明。
- [ ] 资料变化检测只读：新增文件/投递夹识别为 new，已归档文件被外部修改识别为 changed，被删除识别为 missing；检查前后文件 mtime 与 sha 不变，不自动修复/删除；有处理任务时跳过；定时检查可配置（默认 15 分钟，0 关闭）。
- [ ] 变化检测返回 skipped（与扫描预览同一判定，如可抽取类型超 256 MB）；new/changed/missing 为空但 skipped 非空时仍算有未处理项。边界：>8MiB 的已归档文件仅按大小校验，同尺寸内容改动不会报 changed（≤8MiB 文档按记录 sha 校验）。
- [ ] 已取消任务从默认 jobs 列表隐藏（includeHidden 可审计，返回全部记录不受 50 条限制），不能被续跑（WIKI_JOB_CANCELLED）或重新分类；dismiss / dismiss-finished 只隐藏任务记录，不移动或删除任何文件。
- [ ] 首次接管不重排已有分类目录、不重放旧队列；旧 raw 不自动入蒸馏任务。
- [ ] 低置信可手选类别；同名异内容停止而不覆盖。
- [ ] Python 自动发现并显示能力；缺依赖安装必须先获确认。模型渠道/模型使用宿主列表与默认选择。
- [ ] 解析失败/超时单项可见，partial/none 不当事实页，raw 不参与普通召回。
- [ ] 反复扫描不重蒸；取消后不接纳旧结果；中断任务手动续跑。
- [ ] 模型建议更新旧页直接写入（仅当页面 active 且 scope 与任务一致），写入前用当前字节哈希与清单复核；外部已改则报 WIKI_EXTERNAL_EDIT_CONFLICT 失败且原文不变，log.md 有「更新时间/页面/来源 sha」记录，不产生待审候选。
- [ ] 已知边界：蒸馏更新只替换页面正文与 front matter，不改页面文件名/relPath；若模型给出新标题，index.md 中该页既有条目不会随之刷新（index 只追加新页，不重写既有行），需重建索引或人工修正。
- [ ] 自动回写保持开启并跟随会话选择：未选择库时不召回、不写、不排队自动提取，界面统一「未选择知识库」；自动路径不按库类型分支（普通库与已接入库一致），普通库回写行为不变。
- [ ] 命令写入 `conversation_save`：目标=会话选中的知识库（未选择拒绝、不回退项目默认库），需 conversationEnabled=true 且有直接写权限；固定新建 wiki/notes/<hash>.md，无 targetPageId、不覆盖既有页；同 session+turn+title+body 幂等；返回真实 entryId/pageId/relPath 与首段摘要；provenance 记录 sessionId/turn/（如有）sourcePath；失败返回明确原因码且界面不出现“Wiki/普通库”字样。
- [ ] 会话内选择库：输入框旁「知识库」选择器默认不使用知识库；单选切换只保留一个生效会话挂载，切换在下一次回答生效；选择即授权本会话写入（writeMode=direct），命令写入仍需 conversationEnabled=true；未选择时不召回、不写、不排队自动提取，命令写入返回未选择原因；失败显示原因。

## 中断与回退

- [ ] 在写前、部分目标已写、文件写完但索引未提交时分别中断并恢复。
- [ ] 中断后有人修改文件时，恢复保留第三方字节和候选，不覆盖。
- [ ] 不允许多个进程同时写同库；当前没有跨进程文件锁。
- [ ] 验证原件、工作区、外置 raw、数据库一致快照、旧队列和 history 备份可恢复。
- [ ] 上游回退使用独立 profile 和干净普通库快照，不打开混合 fork 数据库；切换后的普通库新记录不能丢失。
