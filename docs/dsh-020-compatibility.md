# DSH 0.2.0-rc.2 兼容说明

本次发布版本：2.13.1，适配 DSH 0.2.0-rc.2。此前 2.13.0 安装包不因此获得新宿主兼容声明。

- 已验证宿主：DSH 0.2.0-rc.2；Node.js ^22.19.0 或 >=24.0.0。
- 宿主版本依赖已更新；知识库和主题补充了可供安装器识别的 DSH peerDependencies，不再仅依赖 README 描述。
- 七个插件合计 1,213 项测试通过，1 项原有跳过；隔离宿主验证召回、回写、伙伴次轮权限、配置保存及重启持久化，浏览器错误为 0。
- 工作区已检查桌面、390px 手机和 1024px 平板宽度；Desktop Origin 检查不等同于完整 Windows/macOS 客户端端到端测试。
- 未触发真实渠道消息、付费模型生成或远程 SSH 操作；不保证所有外部服务兼容。
- 新兼容构建面向 DSH 0.2.0，不应直接覆盖旧宿主安装。升级时保留旧宿主镜像、配置和数据卷，回退须使用配套备份。
- 不修改 DSH 核心源码；原有功能和数据保留。
