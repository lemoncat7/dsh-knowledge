# Wiki 接管版使用与交接

## 当前交付口径

这是基于 Knowledge 2.22.7 的本地 Wiki 扩展候选版本。已完成构建和针对性回归，目录选择已获用户单项确认；完整入库、权限与回退仍需继续验收。安装及功能验证应先使用独立目录与 profile，不直接改动真库。

## 准备

- Node >=24.9；先安装项目依赖。脚本路径和锁文件以交付源码为准。
- 页面自动发现 Python 3 并检查 pypdf、python-docx、python-pptx、openpyxl、xlrd；缺依赖时由用户确认后安装。旧 `.doc`、视频、安装包和压缩包仅登记。
- 原件、raw、Wiki 工作区均使用副本。工作区先放好本库的 schema.md，原件根目录用来投递，已有分类目录不重新归类。
- 先在 Knowledge 管理台创建一个空知识库，Wiki 页中绑定该库。不能把已有普通库直接转成 Wiki（防止普通投影污染）。

## 接管旧 Wiki

1. 停止旧插件的 watcher/蒸馏队列，不清空队列，不再解除暂停。
2. 备份原件、Wiki 工作区、外置 raw、数据库及 WAL 一致快照、旧 kbs.json、queue.json、history。先验证备份能恢复。
3. Wiki 管理页配置 sourceDir/workspaceRoot/rawDir。根目录必须已存在；成文使用 workspaceRoot/wiki。
4. 点击「只读对账」，检查格式错误和超长成文页。不要直接对生产目录运行。
5. 选择明确的项目范围（或明确授权全局），点击「登记已有 Wiki」。此操作只增身份清单和索引，不重写旧 Markdown、不排队旧 raw。
6. 搜索、挂载、引用与重启验收后，才安排旧插件卸载。旧 history 不被自动搬运或删除，备份独立保留。

## 目录选择

- Windows 原生目录选择是默认入口，站内浏览为可选备用方式。原生结果使用 ASCII JSON/Base64 UTF-16LE，避免依赖系统代码页。
- 站内浏览采用共享弹窗、快捷位置、路径/上一级、文件夹筛选和当前选择；读取失败或加载中不能确认。关闭时撤销请求，不修改文件。

## 新资料一次点击入库

- 把新文件放 sourceDir 根目录。页面自动发现 Python，模型通过宿主渠道/模型下拉选择，默认优先当前默认模型。确认资料外发许可并选择项目范围。
- 点「扫描并入库」；任务依次分类、归档、抽取、蒸馏。
- 原件不改文件名。同名异内容停止，人工处理；不要为了继续任务覆盖原件。
- 低置信点击「指定分类」。失败可查阶段与错误后重试；进程重启后的旧任务需明确续跑，不自动重放。
- 仅 full 抽取进入成文，partial/none 放工作区 _meta/待补抽。
- 模型无文件或 Shell 工具。结果由宿主写入文件并更新索引。
- 模型建议替换现有页时，在「蒸馏更新审核」看候选全文并批准/拒绝；批准后回任务重试以完成素材回执。

## 会话与人工编辑

- 普通 Knowledge 挂载提供成文检索；新增 @ 的「Wiki 知识页」源。签发引用前核对当前会话和挂载，分页读取沿用 knowledge_read。
- 管理台打开页可编辑；保存带原文件哈希，有外部修改时报冲突。
- 文档标准独立编辑；不要让模型改标准。启用对话成文前先确认该库标准允许 conversation 证据，不能用伪造原件来源。
- 文件改动后用「刷新索引」。文件删除后派生索引归档，旧版本仍在数据库；当前实现不提供自动目录监视/可靠外部重命名绑定 UI。

## 中断与回退

- Wiki 提交不是多文件磁盘原子事务。恢复按钮按日志补完；若发现第三方内容，停止并保留候选，不自动覆盖。先保存整个工作区再人工处置。
- 不要运行官方版直接打开含 Wiki 活动索引和候选的混合数据库。
- 回退用独立 profile、经验证的干净普通库快照；切换后普通库有新增记录时先导出并核对，不用旧快照直接覆盖。
- 回接 fork 时先恢复工作区元数据和文件，再登记/刷新索引。不要删除 `_meta/knowledge`；它不只是可重建索引，还存身份、项目权限与来源。

## 已知限制（必须验收）

- 针对性测试与本机安装不代表全套通过；已有 Windows 基线失败/超时须保留披露。目录项以外的完整业务验收未确认。
- 当前成文目录固定 wiki；任意自定义 pageDir、递归投递目录、实时 raw 树及监视器未做。
- 同库任务有进程内管理，但跨进程/外部编辑器 CAS 到替换之间仍有竞争窗口；不要运行多个实例写同库。
- 归档使用同目录硬链接无覆盖发布，目标卷不支持硬链接时会失败而非降级覆盖。
- 新原件版本区分采用完整 SHA，但旧 raw/source/wiki 全量语义对账、旧 history 自动迁移尚未实现；当前存量导入主要针对成文页。
- 使用独立的 `knowledge-archive.csv` 记录本插件归档操作；不重写未知格式的旧清单。素材任务与独立完成回执可查。
- @ 搜索按挂载分页，扫描有每库 10,000 条上限；当前没有完整的大库压力验证。
- 自动检测外部重命名、原生安全 replace/共享锁、完整权限标签与版本档独立恢复、全套回退自动化工具未完成；不能宣称满足 v3 所有验收。
