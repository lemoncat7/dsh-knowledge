# 知识库交互试用版

分支：`feat/knowledge-stepper-interactions`。本地包：`2.13.12-stepper.9`。

此文件保留试用过程记录；正式合并版本与升级说明见 [2.13.12](./releases/2.13.12.md)。

参考 React Bits Stepper 的分段导航、圆角边框与按钮反馈，自行实现原生 DOM 版本；不引入 React/Motion 到管理端，不改变存储和接口协议。

## 试用范围

- 待审核导航角标独立预取计数，不读取候选正文、目标文档或评审组件；进入审核页才加载列表。后台完成只更新角标，不重建正文，切页与窗口恢复按 30 秒限频刷新；审核结果覆盖旧计数，失败保留已知数量。
- 拖放目录与知识分组采用整块泛白范围及目标文字提示，嵌套落点只高亮最近目录，取消后清理。
- 点击文档即并行请求编辑器与正文；笔记目录路径和知识关联笔记独立加载，不再阻塞正文，也不重建正在编辑的正文。版本内容并行读取仍校验最新版本。
- 静态脚本支持 gzip 内容协商，编辑器传输约从 522 KB 降至 164 KB；保留未压缩兼容响应和版本化缓存。
- 会话右侧栏分组默认折叠，搜索时展开；知识文档与笔记文档共用正文右侧的独立大纲栏，不在正文顶部插入目录。正文与大纲各自滚动，点击标题只定位正文、不滚动宿主会话；支持收起／展开以腾出阅读空间。
- 修复知识文档同库拖动换组误报跨库：落点依据实际拖动载荷查询来源，回收拖动状态延后到事件分发结束。跨库仍拖到知识库名称。
- 笔记目录列表行、展开的整块目录范围、目录空白均可接收拖放，嵌套目录优先接收，外部文件导入保持支持。
- 错误提示 8 秒自动关闭，普通提示 4.2 秒；悬停或键盘聚焦时暂停，保留手动关闭。
- 审核页正文独立滚动，不再穿过透明标题栏；分组折叠箭头不再被外层知识库展开样式覆盖。
- 更新会话指令：@ 引用、整篇修改的完整预览与一次确认、明确删除和历史版本入口。
- 知识、笔记、挂载、审核、回写工作区共用按钮、选项、下拉菜单及弹窗交互样式。
- 日报嵌入工作区和宿主设置的控件同步对齐。
- 创建知识库分为基本信息、收录规则、确认创建；直接点击后续步骤仍执行前置校验。
- 所有弹窗统一居中，内容自适应高度，超高时内部滚动；旧的侧栏入口共用居中弹窗，不再铺满右侧。
- 编辑知识库保留单页表单，删除和重命名保留直接确认，不人为增加步骤。
- 保存失败显示在弹窗内；未保存关闭统一使用“继续编辑 / 放弃修改”确认弹窗，知识库和日报共用同一个组件。
- 关闭按钮、遮罩、Esc、取消均需确认；默认继续编辑，保存中不能关闭，成功保存不会再次询问。
- 右侧栏同步使用分段轨道、圆角按钮和短菜单动画；知识库选择支持方向键、首尾定位、Esc 关闭和焦点恢复，长标题悬停可查看完整内容。
- 日报弹窗底部操作区独立于滚动正文，保存按钮仍关联原表单；更多菜单支持键盘操作和外点关闭。
- 笔记历史在低高度横屏中自然排布并内部滚动，避免时间线挤掉正文。
- 页面切换立即更新导航与目标标题，不再等待接口完成后才切页。保留侧栏、顶栏、背景与滚动容器，只替换内容；慢请求 180ms 后显示轻量占位和提示，不插入整页骨架。重复后台渲染不重启等待提示，快速切换忽略旧请求。
- 数据就绪仅对内容做 120ms、90% 到 100% 不透明度的轻过渡，不先淡出到空白、不延迟接口结果。快速切换取消旧过渡，减少动态效果模式不播放。
- 历史弹窗打开即确定外框尺寸；复用已读取的当前版本，读取其他版本时保留原正文，失败后可重试。历史列表加载失败在原弹窗内重试，不重复播放入场动画。

## 架构与边界

- `web/interaction-theme.css`：管理端交互视觉层，继承原有主题令牌，不修改阅读区材质与配色。
- `web/workspace-shell.js`：持久页面外框与内容提交，不存业务缓存或执行请求；保留导航按钮焦点和既有半透明材质层。
- `src/design-tokens.ts`：管理端、右侧栏和宿主设置共用圆角、动效时间与缓动令牌。
- `src/knowledge-activity-scope.tsx`：右侧栏知识库选择的键盘与焦点管理。
- `worklog/ui/Dialog.jsx`：日报弹窗与底部操作区；复用统一未保存确认，不承载业务存储。
- `web/dialog-steps.js`：步骤导航、校验、焦点；不执行 API 或持久化。
- `web/dialogs.js`：弹窗生命周期、忙碌状态、错误和关闭保护。
- `web/discard-confirmation.js` / `.css`：共用未保存确认，使用原生顶层 dialog，覆盖 DOM 与 React 弹窗；父弹窗卸载时同步清理。
- 只在打开/关闭/主动切换时播放短动画；无全局动画扫描、常驻循环、全屏背景模糊。
- 动画不影响保存结果或关闭清理；支持 `prefers-reduced-motion`。
- 两个新静态资源均纳入资源版本哈希和服务白名单。
