# DSH 0.1.5 客户端适配

以新版宿主的导航和停靠机制为准；不修改 DSH 核心、槽位声明或权限校验。

## 边界

- `main-panel-compat.ts`：新版注册根级 keyed `main`，通过 `layout.selectPanel` 打开。切离面板时释放插件打开状态；失败时撤销注册；清理不抢占其他面板。
- 新版根级面板不保证会话级 props，页面从会话 store 获取当前会话。
- 知识库与 SSH 的 `docked-panel-compat.tsx`：静态 tab type + 官方 `sidebar.right.pane.tab`，会话和停靠布局归宿主管理。不同插件标签可以共存，隐藏内容停止后台轮询。
- 待打开操作等待会话界面提交；切换会话、关闭、卸载会取消尚未执行的打开。
- 不按版本字符串猜接口。旧宿主缺少 `selectPanel` 时留在原有 conversation/details 分支；旧分支不参与新版停靠布局。
- 类型桥只声明实际使用的新版能力，不把新版运行时或旧版核心包打进插件。

## 验证范围

2026-09-11：隔离 Docker 中的 CLI 0.1.5-rc.1（官方依赖实际包含 0.1.5-rc.2）已验证三个主面板、伙伴打开会话、知识库/SSH 侧栏标签共存、切换和分别关闭、主面板切回会话后再打开；浏览器无 pageerror。

自动测试覆盖旧入口、新入口、注册失败回滚，以及侧栏等待提交、关闭取消、切换会话取消、暂时未挂载与卸载清理。

这不是生产升级记录。未使用真实模型凭据、外部 SSH/FTP 主机或微信发送；真实模型运行、外部连接与数据迁移仍需升级前验收。开发依赖保留旧 SDK 用于回归构建，新接口按隔离宿主实际运行验证。
